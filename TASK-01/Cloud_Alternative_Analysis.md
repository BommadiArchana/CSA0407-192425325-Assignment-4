# Q1 – Cloud Alternative Analysis

## Design Defence

The improved directory structure protects student privacy by providing a separate directory for each student and restricting access through file permissions and Access Control Lists (ACLs). Students can access and modify their own files, while other students cannot access private documents. For group projects, authorised members receive access to shared project folders. Faculty members receive access according to their academic responsibilities. This arrangement protects personal information while supporting secure collaboration.

## Alternative Concept – Cloud Storage

If student files were stored using a cloud service such as Google Drive or OneDrive instead of a shared college server, file storage and sharing would be managed through the cloud platform.

### File Searching and Opening Time

Cloud services allow students to search for files using file names and folders. Files can be accessed from different locations through an internet connection.

However, opening and downloading files depends on internet speed, network availability and cloud service response time. A local college server may provide faster access to users connected to the campus network.

### Storage Used

A college server stores files on its own storage devices. The college must manage storage capacity, backups and additional hardware.

Cloud storage uses storage provided by the service provider. Shared files can be accessed by multiple authorised users without each user necessarily maintaining a separate copy. However, synchronisation, offline downloads and backups may create additional copies.

### Privacy and Security Control

With its own server, the college has direct control over storage configuration, user permissions, access policies and backup procedures. It is responsible for maintaining security and protecting the data.

With Google Drive or OneDrive, the cloud provider manages the underlying infrastructure and provides access-control and security features. The college must configure permissions correctly and manage user accounts. It also depends on the provider's policies and service availability.

### Comparison Table

| Feature | College File Server | Google Drive / OneDrive |
|---|---|---|
| File Access | Mainly through the college network or configured remote access | Through the internet from different locations |
| Search | Depends on server directory organisation and search tools | Provides built-in file search |
| Storage Management | Managed by the college | Managed by the cloud provider |
| File Sharing | Configured using permissions and shared folders | Uses sharing permissions and links |
| Backup | College is responsible for backup | Provider offers cloud infrastructure; backup and retention settings still need management |
| Privacy Control | Direct control by the college | Shared responsibility between college and provider |
| Internet Dependency | Local access may work without internet | Internet is generally required for remote cloud access |

### Advantages of Cloud Storage

- Students can access files from campus or home.
- Files can be shared with authorised project members.
- Storage capacity can be increased according to requirements.
- Built-in collaboration features support group projects.
- The college does not need to maintain all storage hardware itself.

### Limitations of Cloud Storage

- Access depends on internet connectivity.
- Subscription and storage costs may increase as data grows.
- The college depends on the cloud provider's availability and policies.
- Incorrect sharing permissions may expose private files.
- The college has less direct control over the underlying storage infrastructure.

### Conclusion

Cloud storage provides convenient access, file sharing and flexible storage capacity for students and faculty members. However, a college-managed server provides more direct control over storage and access policies. A suitable solution is to use a properly secured college server or a managed cloud service with individual student accounts, restricted permissions, shared project folders and regular backups.
